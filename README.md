# Sister Abena Paano Tea Bread

A responsive static website built with plain HTML, CSS, and JavaScript. It does not require Next.js, React, npm, or a build step.

## Files
- `index.html` — website content, WhatsApp order form, and customer feedback form
- `styles.css` — responsive styling
- `script.js` — mobile navigation, current year, and WhatsApp form handling

## Run locally
Open `index.html` in a web browser. Submitting an order or review opens WhatsApp with a message prepared for the bakery; the customer must press Send in WhatsApp.

## Publish on Vercel
1. Upload the files in this folder to the root of a GitHub repository.
2. Import that repository into Vercel.
3. In Vercel project settings, select **Other** as the Framework Preset if asked.
4. For a plain static site, no build command is required; serve `index.html` from the project root.
5. Deploy.
