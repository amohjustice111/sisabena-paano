# Sisabena Paano Ad Maker

Create polished 30-second, 9:16 social adverts for Sisabena Paano. Read `references/creative_brief.md` and `references/style_guide.md` before planning; they define the approved duration, scene rhythm, visual tone, CTA, and factual constraints.

## Inputs and factual grounding

1. Treat the live Sisabena Paano website as the source of truth for brand name, products, services, features, audience benefits, visible UI, and factual wording. Read the supplied site URL directly; if access fails, say so and use only neutral, non-claiming brand imagery and the approved closing URL.
2. Inspect any supplied logo, product photograph, existing brand asset, or prior ad before making new assets. Preserve recognisable design, text, packaging, and brand colors.
3. Never infer prices, delivery areas, guarantees, inventory, testimonials, product details, services, or customer outcomes from the brand name or an earlier ad. Write down only website-supported claims.
4. Ask a concise question when the user requests a factual statement not visible on the site or in supplied material.

## Production workflow

1. Build a factual content sheet from the live site: brand name, exact URL, actual offerings/features, suitable supported customer benefit, visual/UI evidence, and any approved CTA. Keep a record for script, captions, and QA.
2. Prepare a 30-second vertical concept and voice-over using the five-scene structure in the creative brief. Keep captions verbatim-aligned to the approved narration; do not add screen text that asserts unsupported facts.
3. Present the concise script and factual claim list for approval before paid asset production. If the site cannot be accessed, explicitly mark the plan as neutral-brand mode and obtain approval before continuing.
4. Generate or source realistic moving visuals in batches. Where website UI is shown on a laptop or phone, use accurate readable captures or faithful supplied imagery; do not fabricate app screens, listings, features, or interfaces. Design footage with clean vertical safe areas for captions.
5. Create professional voice-over in the requested language; otherwise use clear, warm English narration based only on approved website evidence. Pair it with uplifting, unobtrusive licensed/created instrumental music that stays below the narration.
6. Read the installed `capcut-render` skill before composition. Build the multi-scene vertical draft with correct clip timing, voice-over, caption timing, music fades, smooth transitions, and the supplied final CTA. Render through the CapCut route.
7. Review the render for duration, 9:16 framing, factual accuracy, readable website/UI, caption accuracy, speech clarity, music balance, legible final screen, and absence of unsupported claims. Deliver only the final MP4 unless the user requests a review package.

## Required scene arc

Follow the detailed timing and wording rules in the references. Default scene rhythm:

- 0–5s: premium, intriguing branded opening with genuine temporal movement.
- 5–12s: modern laptop and smartphone showing the actual website, naturally browsed by a realistic person.
- 12–21s: only actual site-supported services, products, or features and their evidenced convenience/value.
- 21–26s: happy, confident realistic customers interacting with the brand context; avoid implying unverified results.
- 26–30s: end screen using the exact approved brand name, CTA, and website URL.

## Rendering and delivery

- Use the installed `capcut-render` skill for all timeline composition, subtitles/captions, audio mixing, transitions, and final rendering. Do not substitute an FFmpeg composition.
- Keep the full video vertical 9:16, approximately 30 seconds, with captions readable on TikTok, Instagram Reels, and Facebook Reels.
- Use the exact closing text defined in `references/creative_brief.md` unless the user approves a replacement.
- Verify the final render is non-empty and playable before delivery.

## Failure and revision handling

- If the website is unavailable, do not invent its contents: use neutral branded visuals, the logo/brand name if supplied, and the approved URL only after user approval.
- If UI text cannot be captured clearly, omit the close-up or substitute an accurate neutral device interaction; never create fake readable UI.
- For a brand, claim, script, or visual-direction change after approval, revise the factual sheet and request approval before regenerating affected scenes.
- Preserve approved scenes and replace only the affected material where feasible. Report any missing website evidence or composition dependency rather than silently changing the plan.
