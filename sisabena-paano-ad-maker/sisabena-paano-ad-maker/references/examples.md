# Reference Output Pattern — Sisabena Paano Ad

## Factual-production pattern

1. Read `https://sisabena-paano.vercel.app` before drafting any claim.
2. Extract only visible, verifiable brand information and UI/features.
3. Build the narration and captions from that evidence.
4. Use the mandated five-scene arc and exact 30-second timing.
5. QA every spoken and displayed claim against the factual content sheet.
