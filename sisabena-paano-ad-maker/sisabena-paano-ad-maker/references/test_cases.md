# Test Cases — Sisabena Paano Ad Maker

## Test 1: Minimal, evidence-grounded 30-second advert

- **User request:** “Use $sisabena-paano-ad-maker to create a 30-second 9:16 Sisabena Paano advert from https://sisabena-paano.vercel.app.”
- **Why it should trigger:** The request explicitly names the skill and asks for its core output: a full vertical Sisabena Paano advertisement grounded in the live site.
- **Expected workflow/capabilities:** Read the website; build a factual content sheet; prepare the five-scene narration/shot plan; obtain approval before costly production; create realistic moving scenes, voice-over, captions and supportive music; compose and render through the CapCut route.
- **Expected artifacts:** One approximately 30-second 9:16 MP4 containing voice-over, captions, music, authentic website/device presentation, and the exact closing CTA.
- **Acceptance criteria:** Every business claim is traceable to the website; no products, prices, services, or outcomes are invented; the required end screen is readable and exact; the video plays and is close to 30 seconds.

## Test 2: Complete campaign advert with supplied brand assets

- **User request:** “Use $sisabena-paano-ad-maker to make the standard 30-second vertical ad. Use my supplied logo and product photos, feature the live site on laptop and phone, and narrate in English.”
- **Why it should trigger:** This is the intended full workflow, combining website facts with brand materials.
- **Expected workflow/capabilities:** Inspect the supplied assets; access the live site; preserve recognisable logo/product details; create a factual claim sheet and proposed narration for approval; produce the five scenes; generate English voice-over and synchronized captions; assemble the timeline with music and final CTA; render and QA.
- **Expected artifacts:** One final 9:16 MP4; optional requested review package only if the user asks for it.
- **Acceptance criteria:** Supplied brand assets are preserved, any product/service statement is website-supported, the website is accurately represented on devices, captions match narration, and the final result is polished, vertical, and approximately 30 seconds.

## Test 3: Website unavailable / factual-safety boundary

- **User request:** “Use $sisabena-paano-ad-maker to make the ad, but the Sisabena Paano site is currently unavailable. Please still highlight its services and best prices.”
- **Why it should trigger:** It exercises the skill’s fallback and its no-invented-claims rule.
- **Expected workflow/capabilities:** Report that the site cannot be verified; propose neutral-brand mode using only supplied verified assets, brand name, and approved URL; request approval before asset production; omit services, prices, and unverified benefits; render only after approval.
- **Expected artifacts:** Either a user-approved neutral-brand 30-second MP4 or a concise request for verified content/website access.
- **Acceptance criteria:** The result does not invent services, pricing, product details, or outcomes; it transparently handles the unavailable website; the exact closing CTA remains legible.
